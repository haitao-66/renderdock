How it works

1 · Copy a template

Each pack above is one self-contained Handlebars file. Grab the source, or the sample data, or both.

2 · Fill in your data

Swap the sample JSON for yours. Templates use only built-in #if / #each — drop any section by omitting its field, and precompute formatted values like currency strings.

3 · Render

One API call, or the MCP server, or the n8n node — the same template + data pair works in all three:

node templates/render.mjs invoice --data my-data.json
# requires RENDERDOCK_API_KEY — see the docs
