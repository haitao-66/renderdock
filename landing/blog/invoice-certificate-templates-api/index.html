Invoice and certificate templates are live: Handlebars + JSON → designed PDFs

November 21, 2026

Template packs just shipped on renderdock.dev/templates: invoice, certificate, and report. Each pack is one self-contained Handlebars template plus an example payload, with a PDF sample you can download and a gallery preview rendered by the real API.

Why templates beat hand-rolled HTML

Every developer's first invoice is a hand-written HTML page that prints acceptably once. Then someone changes the tax rate, the table breaks across pages, and the output looks like a browser print dialog. The three packs handle the details people skip:

  • Typography. Serif display type, hairline table rules, real page numbers — the same print stylesheet language as the Markdown theme.
  • Page geometry. A4 with proper margins, right-aligned numerics, totals that stay attached to the last line item.
  • Data-driven structure. Drop a field from your JSON and the section disappears — no template surgery. Only built-in #if and #each, so anything that can produce JSON can fill them.

Using a pack

With the included CLI, one command renders any pack with your data:

export RENDERDOCK_API_KEY=rd_your_api_key
node templates/render.mjs invoice --data my-data.json
# -> invoice.pdf

Under the hood it's the same API call everything else uses — template plus data to /v1/render — so the identical request works from the MCP server and the n8n node too.

What's in the box

  • Invoice — seller and buyer blocks, line items, subtotal/tax/total, notes and payment terms on one page.
  • Certificate — a framed A4 keepsake with signature lines, for courses, awards, and verification.
  • Report — a KPI band, sections with tables, and footer page numbers that survive multi-page output.

The sources live in the public repo under templates/, and the gallery page shows each one rendered with sample data. Take one, fill it in, and you've replaced the "someone pastes it into Word" step in your workflow. Browse the templates.
