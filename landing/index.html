Three ways in

REST API

Send one request, get a file back. Works from any language.

curl -X POST https://api.renderdock.dev/v1/render \
  -H "Authorization: Bearer $RENDERDOCK_KEY" \
  -d '{"markdown": "...", "format": "pdf"}'

MCP server

Give your agent a render tool. Files come back as paths, not context.

npx @renderdock/mcp

n8n node

Drop rendering into any workflow — invoices, reports, screenshots on a schedule.

npm install n8n-nodes-renderdock
